# CBR+PNK

## Règles de Base en Texte Simple (Version Française)
_v1.6 - Avril 2024_

**CBR+PNK EST UN JEU FORGED IN THE DARK POUR DES PARTIES ONE-SHOT D'ACTION CYBERPUNK CINÉMATOGRAPHIQUE.**

Les personnages **JOUEURS (PJ)** sont des **COUREURS** — mercenaires, criminels, rebelles vivant dans l'ombre d'un monde ultra-violent et impitoyable. À chaque partie, ils forment une équipe prête à tout risquer pour atteindre leur **Objectif** lors d'une **DERNIÈRE COURSE**.

Leur contact est simplement appelé **OPÉRATEUR**, une voix plate et anonyme dans leur comlink qui les considère comme de simples ressources jetables.

La **MÉGAPOLE** peut être n'importe quelle mégalopole surpeuplée, rongée par la haute technologie, la lutte des classes, la publicité intrusive, la corporatocratie, les services automatisés de mauvaise qualité, l'effondrement climatique, la quête vaine d'humanité au milieu de tout cela, etc.

Le **RÉSEAU** est composé de serveurs à travers le monde où les données circulent frénétiquement. En surface, on trouve les archives publiques, les flux médiatiques, les applications quotidiennes. Les informations sensibles sont protégées par des **PCI** (Protocoles de Contre-Intrusion). Les mégacorporations et les individus obscènement riches possèdent leurs propres serveurs privés, accessibles uniquement depuis des terminaux situés dans des installations ultra-sécurisées.

Le **MAÎTRE DU JEU (MJ)** utilise les règles pour créer un monde dynamique autour des PJ. Il/elle aide à organiser la conversation pour qu'elle se concentre sur les éléments les plus intéressants du jeu.
